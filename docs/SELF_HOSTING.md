# AWG self-hosting policy

AWG governs its own evolution after the bootstrap gates are complete. Every
design or conceptual change to AWG starts with a versioned specification and a
passed autonomous check. The check is repeated before implementation, and the
result remains separate from oracle approval, implementation evidence, AWQ
quality evidence, CI, and release evidence.

The trusted seed is the bootstrap specification and its checker. A change to
the bootstrap specification, formal checker, or this self-hosting policy must
introduce a successor specification and a new autonomous result before it can
be used. Routine operational maintenance still declares a bounded specification
and may use the explicitly lighter operational authoring method.

Coordinator owns AR identity, dependencies, revisions, claims, and lifecycle
transitions. AWQ owns quality profiles and evidence requirements. AWG owns the
decision and specification layer; passing one layer never substitutes for
evidence from another.
