# AutoGen and Microsoft Agent Framework decision

The public snapshot records AutoGen as maintenance mode and points new users
to Microsoft Agent Framework (MAF). AWG therefore treats AutoGen as a legacy
comparison subject and MAF as the candidate path for new-work evaluation, not
as an AWG runtime dependency.

The decision compares user feedback, termination, persistence, and authority.
Neither project’s feature surface replaces AWG’s ranked alternatives,
revision-bound oracle decision, bounded authority, or separate quality and
implementation evidence. A future MAF adapter requires its own AR, exact
revision, sandbox, and tests.
