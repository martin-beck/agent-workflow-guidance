# Bounded delegation and authority

An oracle approval is authority only for the declared task and scope, until
the declared expiry. The packet must include enough context and alternatives
for informed rejection. Rejection power is explicit; an approval record cannot
launder unresolved uncertainty or expand its own scope.

Every disposition records task identity, scope, expiry, alternatives count,
context presence, rejection affordance, and disposition. Expired and rejected
records remain evidence but cannot authorize execution. The offline checker
validates these boundaries and does not claim accountability or runtime safety.
