# Discussion packet and specification review

Each discussion point is independently authorized. A packet exposes bounded
context, ranked alternatives, evidence gaps, applicability/outcome/downstream
confidence, trade-offs, implications, reversibility, and exact specification
and formal-check references. Every response binds to the Coordinator task
revision. A user-added solution is evaluated with the same fields before it
can be selected; one point never authorizes another.

The state-side offline checker and synthetic fixtures enforce this contract.
Approval remains oracle intent, separate from implementation and quality
evidence; private prompts and transcripts are not public state.
