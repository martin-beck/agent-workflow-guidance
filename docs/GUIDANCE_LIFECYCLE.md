# Reusable guidance lifecycle

Reusable oracle guidance is a scoped, provenance-bearing record—not a
permanent authorization. A changed repository context, expiry, or observed
counterexample moves it to revalidation. Only a successful revalidation may
create a new bound record, and the new record retains the predecessor.

The offline contract demonstrates active reuse, expiry, and changed-context
invalidation. It fails closed for stale or over-generalized guidance.
