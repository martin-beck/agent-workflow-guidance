# Contributing

Read `AGENTS.md` and the protocol documents before changing a contract. Keep
the product repository focused on AWG records, schemas, reference behavior,
and public-safe documentation. Use the companion state repository for task
coordination.

Every change needs a focused test or fixture, explicit privacy review, and a
clear statement of what is and is not proven. Include a DCO trailer:

```text
Signed-off-by: Martin Beck <martin-beck@example.invalid>
```

The placeholder address above is documentation only; contributors must use
their own configured identity when committing.
